로또용지 3종 앱

위에서부터 자동, 반자동, 수동 용지입니다. 모바일에서는 아래로 스크롤하며 3장을 순서대로 볼 수 있습니다. 선 연결은 항상 오름차순 기준으로 이어지고, 자동/반자동의 제외수는 별도 초기화 버튼으로만 지워집니다.

이 영역의 저장 목록은 앱을 껐다 켜도 유지됩니다.

구매한 번호 목록

구매 횟수 내림차순, 동률이면 번호 오름차순으로 정렬됩니다. 1~45 전체 번호가 모두 표시됩니다.

자동 로또용지

번호를 직접 선택하지 않고 생성합니다. 제외수 설정 후 생성하면 제외된 숫자를 빼고 6개가 랜덤 생성됩니다.

1번 용지 · 자동
제외수
없음
현재 상태
제외수 설정 후 생성하거나 바로 생성할 수 있습니다.
자동 용지는 제외수 설정 모드일 때만 번호 클릭이 가능합니다.
초기화는 생성결과만 지우고 제외수는 유지합니다.

반자동 로또용지

원하는 번호 1~5개를 직접 선택하고 생성하면 나머지 숫자만 자동으로 채워집니다. 선택수와 제외수가 겹치면 경고 후 생성되지 않습니다.

선택수

기본 클릭은 선택수 입력입니다. 제외수 설정 모드를 켜면 같은 번호판에서 제외수를 입력합니다.
초기화는 선택수와 생성결과를 지우고, 제외수는 유지합니다.

수동 로또용지

원하는 숫자를 직접 찍어보고 조합 정보를 확인하는 용지입니다. 생성 버튼은 없고 최대 6개까지 직접 선택할 수 있습니다.

저장된 번호

저장 버튼으로 누적 저장하고, 복사 버튼으로 저장된 조합 전체를 클립보드에 복사할 수 있습니다.
